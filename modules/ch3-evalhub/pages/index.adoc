= Model Evaluation with EvalHub

Goal::

Evaluate LLMs using EvalHub providers, benchmarks, and collections on Red Hat OpenShift AI.

This chapter describes the main concepts and the process for running and monitoring evaluations using EvalHub with Red Hat OpenShift AI (RHOAI).
Then it shows how to find and run a simple and quick benchmark, so you gain some familiarity with EvalHub before you attempt to run larger and longer evaluation collections.
