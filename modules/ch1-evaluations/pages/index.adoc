= Introduction to MLFlow and EvalHub

Goal::

Understand how MLFlow and EvalHub relate to agentic applications and to Red Hat OpenShift AI.

WARNING: Work In Progress

This chapter introduces MLflow and EvalHub in the context of Red Hat OpenShift AI, focusing on features relevant to generative AI and agentic applications.
You will learn about the need to evaluate agentic applications and their components, such as large-language models (LLMs), and how it differs from tradditional software engineering testing practices.
